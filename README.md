Solano Vice — an original 2D top-down open-world crime game built for make.fun's "Make GTA 6" bounty. Explore the coastal city of Port Solano on foot and by stolen car, dodge traffic and pedestrians, outrun the police across a 0–5 star wanted system, and play six story missions for fixer Mara Voss — from a timed delivery to a five-star finale chase to the docks.

Controls: WASD/arrows to move and drive, Shift to sprint, Space/J to punch, E/F to steal and enter cars, H for the horn, Esc/P to pause. Progress saves to localStorage.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```
